---
title: Create bucket
api: "PUT /{bucket}"
---

<ParamField path="bucket" type="string" required>
 Bucket ID. Must match `[a-z0-9_-]{4,64}`.
</ParamField>

## Response

| Status | Meaning |
| ------ | -------------------------------------- |
| `201` | The bucket ID is valid. Returned on every call, whether or not streams already exist in the bucket. |
| `400` | The bucket ID is invalid. |

<Note>
`PUT /{bucket}` validates the bucket ID and changes no state. Buckets are implicit: a bucket exists once a stream is created in it, so creating the bucket first is optional. It is kept for clients that do so.
</Note>

<RequestExample>
```bash Example
curl -X PUT http://127.0.0.1:4437/demo
```
</RequestExample>
