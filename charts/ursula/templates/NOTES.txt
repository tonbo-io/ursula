Bootstrap:
  The meta group seeds each Raft group once, at bootstrap, on three
  consecutive pods by node id (all pods when there are three or fewer), and
  the first of them initializes it once every voter reports it empty and no
  leader. A replica that ever held its group never initializes it again.

Rollouts and scaling:
  The StatefulSet rolls by RollingUpdate under Parallel pod management, paced
  by each pod's readiness probe. Start an upgrade only once
  `ursulactl verify-cluster` passes.
  Raising server.replicaCount from 3 or more adds nodes that register and hold
  no group: move groups onto them with `ursulactl placement move`.
  Lowering it removes the highest node ids for good. First run
  `ursulactl node decommission --node <id> ... --wait` for every id above
  the new count, which must keep the meta voters (ids 1 to 3), then lower
  the count and delete the dropped pods' PVCs. A single node never grows.
{{- if .Values.server.scaleCheck.enabled }}
  A pre-upgrade and pre-rollback hook refuses a change of the count that
  breaks these rules.
{{- end }}
